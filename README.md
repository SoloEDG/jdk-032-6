# 骨牌造境

一个本地运行的多米诺、机关连线与风场物理工作台。可以在桌面直接绘制不同方向、生效时刻和持续时间的风区，也可以添加很窄、很短的震动带；骨牌会经过扭矩积分、失稳、接触冲量和连锁传递，摆锤采样同一份力场。

## 本地启动

```sh
npm ci
npm run dev
```

在浏览器打开 Vite 输出的本地地址。

## 物理验收

```sh
npm run verify:wind
```

该脚本会验证：

- `t = 0` 时起点和所有刚体均未受力；
- 两个等强、反向、重叠的风区在向量和与平均值上都为零；
- 单独的窄震动带不能推倒临界牌；
- 弱风与窄震动叠加后，临界牌越过失稳角并产生接触；
- 摆锤对同一采样力场产生摆动；
- 每个风区的生效/结束时刻进入回放事件；
- 修改风区参数不会改写已经生成的事件与接触记录。

应用左侧的「运行验收并载入验证剧场」会执行同一组检查，并在场景中载入重叠逆风、窄震动带、未受力起点、接触链和两个摆锤。

## Docker 启动

```sh
docker compose up --build
```
